Escreva em tópicos

Use # para títulos e - para tópicos. Recue com Tab para criar subtópicos.

Veja o mapa

Cada nota vira um ramo do mapa mental. Clique num ramo para abrir ou fechar e para ir até a nota.

Acompanhe a revisão

Marque cada nota como a estudar, revisando ou dominado. O painel mostra o que está parado há mais tempo.

i

Suas notas ficam neste navegador

Não é preciso criar conta. As notas são salvas no próprio navegador e não são enviadas para nenhum servidor. Para não perder nada, ou para levar as notas para outro aparelho, use Exportar backup e Importar no topo de cada caderno.
